# polyisa の文書

このディレクトリには、polyisa の設計文書と設計判断の記録を置く。

## 文書の種類

| 種類 | 場所 | 内容 | 更新の規則 |
|---|---|---|---|
| 設計文書 | `design/` | 採用している設計（実装の有無を問わない） | 設計を変える変更と同じ変更で更新する |
| 設計判断の記録（ADR） | `adr/` | 判断の背景、決定、帰結、代替案 | 承認後は書き換えず、新しい ADR で置き換える（[運用の規則](adr/README.md)） |
| 参照資料の台帳 | `references.md` | 参照する資料とツールの利用条件と、許可する用途 | 資料を使う前に登録し、所有者が利用条件を確認する（[台帳の規則](references.md)） |
| 設計との差の台帳 | `gaps.md` | 設計文書が定める設計と実装との差 | 差を生じる変更と解消する変更の中で、同じ変更として更新する |
| 実装状況 | `status/` | 命令の一覧、完了条件の判定の方法、設計との差の要約 | 手で編集しない。`task status` で生成し、`task check` が鮮度を検査する |

一つの事実は一つの文書にだけ書き、他の文書からはリンクで参照する。実装の進み具合は手で書かず、ISADL の記述とテストの結果から `status/` に生成する。設計と実装の差は、設計文書に書かず台帳に書く。
