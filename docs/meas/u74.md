# SiFive U74 の実機計測

[タイミングモデル](../design/timing.md) の `approx` の較正に使う実機の計測値の記録。
ベンチマークは `guests/riscv/bench/`（ビルドは同ディレクトリの Makefile）。各区間は
`bench_mark[]` への書き込みで挟まれ、実機側は PMU/rdcycle または perf で区間の
サイクルを取り、polyisa 側は同じ区間の仮想時間と照合する。

## 計測値

サイクルは区間ごとの値。相対誤差は `|実機 − polyisa| / 実機`。各区間は
`bench_mark` の書き込み対（開始=偶数、終了=奇数）で挟まれる。depchain・
istream・branch は区間番号 k が `bench_mark[2k]`/`[2k+1]`、stride は区間 s が
`bench_mark[2s]`/`[2s+1]` に対応する。

| ベンチマーク | 区間 | 内容 | 実機サイクル | polyisa サイクル | 相対誤差 |
|---|---|---|---|---|---|
| depchain | 0 | ポインタチェイシング 4096 回 | | | |
| depchain | 1 | レジスタ依存鎖 2^20 回 | | | |
| istream | 0 | 独立演算 8 命令 × 2^18 回 | | | |
| branch | 0 | 予測可能な条件分岐 2^17 回 | | | |
| branch | 1 | 予測困難な条件分岐 2^17 回 | | | |
| stride | 0 | 64B ストライド × 4 周（4MiB） | | | |
| stride | 1 | 512B ストライド × 4 周 | | | |
| stride | 2 | 4KiB ストライド × 4 周 | | | |
