# ADR-0009：ライセンスが決まるまで、他の実装のコードとデータを取り込まない

- 状態：承認
- 日付：2026-10-26

## 背景

polyisa のライセンスは未定である。参考にできる既存の実装とデータは、ライセンスがさまざまであり、どれを取り込めるかは polyisa のライセンスによって変わる。

## 決定

ライセンスが決まるまで、次のことを守る。

- 他の実装のソースコードを、polyisa のリポジトリにコピーしない。変換や移植によるものも含む。
- 外部のデータ（機械可読な ISA の仕様、テストスイート、テストベクタ、タイミングの計測データ）を、リポジトリにコミットしない。テストで使うデータは、取得元と版とチェックサムを固定して、テストの実行の前に取得する（[検証戦略](../design/testing.md)）。
- ISA の記述は、ISA の公式の仕様書とデータシートを読んで書く。
- 外部のツールは、別プロセスとして実行するオラクルと開発の補助としてだけ使う。

資料とツールの利用条件は、[参照資料の台帳](../references.md) で管理する（[ADR-0010](0010-reference-register.md)）。この ADR が有効な間は、台帳のどの項目にも再配布とコードの流用を許可しない。外部のデータの数値（タイミングの計測値など）を ISADL の記述に書き写すのは、台帳でその資料に事実の記述が許可されている場合に限る。

## 帰結

- ライセンスを後でどれに決めても、リポジトリの中身を書き直す必要が生じない。
- 既存の機械可読な仕様からの ISADL の生成など、作業量を減らす手段を当面使えない。
- テストの実行に、外部のデータの取得の手順が加わる。

## 見直しの条件

ライセンスが決まった時点でこの ADR を見直し、取り込めるようになったコードとデータの範囲を、新しい ADR に記録する。
