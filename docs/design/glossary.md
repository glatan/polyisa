# 用語集

polyisa の文書とコードで使う用語を定義する。ここで定義した語は、他の文書では定義し直さずに使う。英語の識別子が対応する場合は括弧内に示す。

## 実行の主体

| 用語 | 定義 |
|---|---|
| ゲスト（guest） | エミュレートされる側。ゲスト ISA、ゲストプログラム、ゲストアドレスのように使う |
| ホスト（host） | polyisa 自体を実行する側の OS と CPU |
| ISA ファミリ | エンコーディングと CPU 状態を共有する ISA の系譜。一つのゲスト ISA クレートが一つの ISA ファミリを扱う。例：x86 ファミリは 8086 から x86-64 までを含む |
| vCPU | 一つのゲストスレッドを実行する仮想 CPU。CPU 状態、ソフトウェア TLB、デコードキャッシュへの参照を持つ |
| 裸実行環境（bare environment） | OS パーソナリティを介さずに vCPU とメモリだけを動かす環境。テストでのみ使う |

## ISA の記述

| 用語 | 定義 |
|---|---|
| ISADL | polyisa の ISA 記述言語。エンコーディング、オペランド、アセンブリ構文、機能、CPU モデル、タイミング表を記述する |
| 機能（feature） | 命令の有無や振る舞いを左右する最小の単位。ISA 拡張（RISC-V の Zba、x86 の SSE2）、ISA のバージョン（MIPS32 Release 2）、アドレス幅（RV64）などを、すべて機能として表す |
| 機能集合（feature set） | 機能の集合。ISA ファミリごとに固定長のビット集合として生成する |
| プロファイル（profile） | 名前の付いた機能集合。ISA のバージョン、規格上のプロファイル（RVA22U64、x86-64-v3）、CPU の世代を表す |
| CPU モデル（cpu model） | 実在または仮想の CPU を表す定義。機能集合、挙動パラメータ、識別情報（CPUID の値など）、タイミングモデルとその表を組み合わせる |
| 挙動パラメータ（behavior parameter） | 同じ命令の振る舞いが CPU モデルによって異なる箇所を表す型付きの値。未定義フラグの値、境界条件での結果、ISA が実装定義とする動作などを表す |
| 実行モード（execution mode） | 実行中に変化し、デコードや意味論を変える CPU 状態の一部。x86 の既定オペランドサイズ、ARM と Thumb の切り替え、SH-4 の FPSCR.PR などを指す |

## 命令の実行

| 用語 | 定義 |
|---|---|
| ステップ（step） | ISA が定める、不可分に実行される単位。多くの ISA では 1 命令、Hexagon ではパケット、IA-64 ではバンドル、x86 の REP 付き命令では 1 回の繰り返しにあたる |
| 命令意味論（semantics） | 命令が CPU 状態とメモリに対して行う操作を、バックエンドトレイトの操作で書いた Rust の関数 |
| バックエンド（backend） | 命令意味論を受け取る側の実装。インタプリタのバックエンドは操作をその場で実行し、IR のバックエンドは操作を IR として記録する |
| ヘルパー（helper） | バックエンドの操作で表すには複雑な処理を、具体的な値に対して実行する通常の Rust 関数。インタプリタは直接呼び、JIT は呼び出し命令を生成する |
| ブロック（block） | 連続するステップの列。ブロックキーで識別し、デコードキャッシュや変換キャッシュの単位になる |
| ブロックキー（block key） | ブロックを一意に識別する値。ページフレームの識別子、ページ内オフセット、実行モード、CPU モデルの世代（機能集合と挙動パラメータの値の版）からなる。CPU モデルが変われば別のキーとして扱い、デコード結果を共有しない |
| 退出（exit） | ステップやブロックの実行が通常の流れを外れること。システムコール、CPU 例外、実行予算の消費、デバッグ停止などがある |
| 自己書き換えコード（SMC） | 実行済みのコードを含むページへの書き込み。対応するブロックを無効化する |

## メモリ

| 用語 | 定義 |
|---|---|
| アドレス空間（address space） | 一つのゲストプロセスから見えるゲスト仮想アドレスの空間。ソフトウェアページ表で表現する |
| ページフレーム（page frame） | ゲストのデータを保持するホスト側のメモリ片。4 KiB 単位で、コピーオンライトのために共有できる |
| ソフトウェア TLB | vCPU ごとに持つ、ゲスト仮想ページからページフレームへの変換のキャッシュ |
| アクセス属性（access attributes） | メモリアクセスごとのエンディアン、アライメントの扱い、アクセスの種類（データ、命令フェッチ、不可分操作）の組 |

## タイミング

| 用語 | 定義 |
|---|---|
| タイミングモデル（timing model） | 命令イベントを受け取り、仮想時間を進める構成要素 |
| 忠実度（fidelity） | CPU モデルが宣言するタイミングの正確さの水準。`none`、`cpi`、`exact`、`approx` の四つがある。定義は [タイミングモデル](timing.md) にある |
| 命令イベント（instruction event） | 退役した命令についての記録。命令の種類、アクセスしたアドレス、分岐の結果などを含む |
| 仮想時間（virtual time） | タイミングモデルが数えるサイクル数と、そこから換算した時刻 |

## OS とプロセス

| 用語 | 定義 |
|---|---|
| 仮想カーネル（virtual kernel） | polyisa のプロセス内で動く、OS のサービスの実装。ゲストプロセス、ゲストスレッド、ファイル記述子、仮想ファイルシステム、シグナル、futex などを持つ |
| OS パーソナリティ（os personality） | 仮想カーネルの上で、特定の OS のシステムコール規約を実装する層。Linux、WASI、Unix V7 などがある |
| ゲスト ABI | ISA、OS パーソナリティ、ABI の変種（MIPS の o32/n32/n64 など）の三つ組。システムコール番号、構造体の配置、定数の値はゲスト ABI ごとに決まる |
| ゲストプロセス | 仮想カーネル上のプロセス。アドレス空間と一つ以上のゲストスレッドを持つ。ホストのプロセスとは対応しない |

## 検証

| 用語 | 定義 |
|---|---|
| オラクル（oracle） | テストで期待値を与える外部の基準。実機、他のエミュレータ、他の逆アセンブラ、公式のテストスイートなど |
| 差分テスト | 同じ入力を polyisa とオラクルで実行し、結果を比較するテスト |
| 重いテスト | 外部のツールかテストデータを必要とするテスト、または nextest の `default` プロファイルの時間の上限を超えるテスト。名前が `heavy_` で始まるテストバイナリに置く |

## 開発作業

| 用語 | 定義 |
|---|---|
| タスク（task） | `Taskfile.yml` に定義した開発作業の手順。`task <名前>` で実行する |
| devtool | タスクから呼ぶ、開発作業のための Rust のコマンド。成果物に含まれない |
| nextest のプロファイル | nextest の設定の単位。実行するテストの範囲と時間の上限を決める。ISA の記述でいうプロファイルとは別のものである |
| 参照資料 | polyisa が参照し、または使用する外部の資料とツール |
| 台帳（register） | 参照資料を、利用条件と許可する用途とともに登録した表。[参照資料の台帳](../references.md) にある |
| 用途 | 台帳で参照資料ごとに許可する使い方。参照、事実の記述、取得して検証に使う、実行、再配布、コードの流用の六つがある |
