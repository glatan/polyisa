# タイミングモデル（`timing`）

`timing` クレートは、ゲスト命令の実行にかかるサイクル数を機能実行と分離して計算する。

## 機能とタイミングを分離する理由

サイクル計算を命令意味論の中に埋め込むと、CPU モデルごとのマイクロアーキテクチャ差が意味論へ混入し、インタプリタ・JIT との両立も崩れる。polyisa では機能実行が退役させた命令列を命令イベント（`InstrEvent`）としてタイミングモデルへ渡し、タイミングモデルから機能実行へ返す情報は現在の仮想時間だけに制限する。

ただし、8086 の命令プリフェッチキューによる自己書き換えコードの挙動や MIPS I のロード遅延スロットのように、機能結果そのものを変える微細構造はタイミング側ではなく機能側で再現する。

## 忠実度の区分

サイクル数を公開資料から確定できるのは主にインオーダー CPU に限られ、アウトオブオーダー CPU の内部構造は非公開部分が多い。この差を明示するため、CPU モデルごとに次の 5 段階の忠実度（`Fidelity`）を宣言する。

| 忠実度 | 意味 | 検証基準 | 主な対象 |
|---|---|---|---|
| `none` | サイクルを数えない（ステップ数から換算） | なし | 汎用モデル、WebAssembly |
| `cpi` | 命令分類ごとの固定サイクル数を加算する | なし（相対比較の目安） | 簡易モデル |
| `exact` | 公開資料または単命令テスト集から確定したサイクル数を再現する | 検証用命令列ですべて一致 | R3000、8088、80486、Pentium、68000 |
| `approx` | パラメータ化したマイクロアーキテクチャモデルで近似し、実機計測で較正済み | 較正ベンチマークで宣言誤差内に収まる | アウトオブオーダー CPU、資料不足の CPU |
| `approx_uncalibrated` | `approx` モデルのうち実機較正がまだ完了していないもの | 同上（較正待ち） | SiFive U74、VAX-11/780 |

`polyisa cpus` は `MODEL_TIMING` を参照し、`approx_uncalibrated` のモデルには `（未較正）` を添えて表示する。

## ユーザーモードでのサイクル数の範囲

ユーザーモードではカーネル処理・割込み・他プロセスによるキャッシュ汚染を再現できないため、次を範囲とする。

- ユーザー空間の命令実行はタイミングモデルで数える。
- システムコールは固定サイクル数（既定 0）として扱う。
- 物理インデックスのキャッシュはページフレーム識別子から作った仮想的な物理アドレスで近似する。

## 汎用モデルと専用モデル

`timing` クレートは ISA 非依存の汎用モデルを提供し、各ゲスト ISA は `guests/<isa>/src/timing.rs` に CPU モデル固有のタイミング表または専用モデルを置く。

| モジュール | 構造 | 主な用途・現行の近似 |
|---|---|---|
| `timing::cache` | L1/L2 キャッシュ階層（セット・ウェイ・ライン・RR/PLRU 置換） | 全モデル共通。立ち退きラインの汚れと書き戻し時間は未モデル（[GAP-0091](../known-issues.md)） |
| `timing::branch` | 相関型方向予測（gshare 近似）、BTB、IJTP、RAS | 全モデル共通。BTB/IJTP は飛び先を持たず登録有無のみ判定、RAS は `pc + 4` 固定（[GAP-0091](../known-issues.md)） |
| `timing::inorder` | デュアルイシュー・インオーダーモデル（発行幅、排他グループ、ペア内ハザード、load-use 遅延、フラッシュ、hint 可変レイテンシ） | SiFive U74 の `approx_uncalibrated` モデル、R3000・80486・Pentium の `exact` 表 |
| `timing::ooo` | dispatch/issue/complete/retire の再帰式近似（ROB・RS・LQ/SQ・ポート占有・排他グループ・キャッシュ・分岐予測、`DECLARED_ERR = 0.25`） | アウトオブオーダー CPU 向け。サイクル単位の資源仲裁やリネーム、誤予測経路の実行効果は持たない（[GAP-0092](../known-issues.md)） |

汎用モデルに収まらない CPU には専用モデルを実装している。

- **x86 8088**（`guests/x86/src/timing.rs`）：4 バイトのプリフェッチキューと BIU バス占有の T-state モデル。
- **m68k 68000**（`guests/m68k/src/timing.rs`）：バスサイクルとプリフェッチのモデル（SST 310,000 件で較正済み）。
- **VAX-11/780**（`guests/vax/src/timing.rs`）：EBOX マイクロサイクル（200 ns）単位の未較正モデル。

## 較正と検証の現状

- **`exact` モデル**：`heavy_timing_r3000`、`heavy_timing_i486`、`heavy_timing_pentium`、`heavy_timing_8088`、`heavy_timing_68000` で検証している（対象範囲の制約は各 ISA 文書を参照）。
- **`approx` 汎用モデル（`heavy_timing_ooo`）**：Skylake 級の `OooParams` に対する合成イベント列を uops.info / Agner Fog の実測 15 測点と比較し、全点が宣言誤差 ±25% 以内に収まることを確認している。なお、IDIV の 1 イベント化（p0 24 サイクル占有）、L1I の直列充填近似（hit_latency 2）、L2 の追加応答 10 サイクル、主記憶 60 サイクル（未較正仮値）、分岐帯域 0.5/clk などの代表値近似を含む。
- **SiFive U74**：`guests/riscv/bench/` に較正ベンチマーク一式と計測記録テンプレート（[実機タイミング計測ガイド](../guides/calibration.md)）を用意しているが、実機計測は未実施のため `approx_uncalibrated` のままである。
- **エンジンとの接続**：`Backend::timing_hint` の意味論からの送出と、実行ループからのイベント供給の完全結線は未完了である（[GAP-0027](../known-issues.md)）。
