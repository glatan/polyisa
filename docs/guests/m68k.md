# m68k

## 概要と対応範囲

68000 の基本命令群一式と、Linux 配布物（BusyBox）の実行に必要な 68020+ 命令（`extb.l`・`divl`/`mull`・`cas`・ビットフィールド命令・full 形式実効アドレス等）を `guests/m68k` で実装している。

- **CPU モデル**：`generic`、`i68000`、`i68010`、`i68020`、`i68030`、`i68040`、`i68060`、`cpu32`、`cfv2`、`cfv3`、`cfv4`（計 11 モデル）。CPU32 は CPU32RM §1.1.6 で確認したとおり 68020 系から BF 系と CAS/CAS2 を削った構成で正確に表し、LPSTOP・TBL 系は未実装（`cpu32` 旗はゼロ件で見える）。ColdFire は CFPRM Rev 3 で確定した事実を配線済み: BCD 算術（abcd/sbcd/nbcd）・rotate（rol/ror/roxl/roxr）・メモリ形シフト・dbcc・exg・chk・rtr・cmpm・movep は ColdFire 全 ISA 版に存在しないため粒状の独立旗（`bcd`/`rotate`/`memshift`/`dbcc`/`exg`/`chk`/`rtr`/`cmpm`/`movep`）に分け、m68000 の implies に載せて cfv 系から外した。ISA_B/C の追加命令（MVS/MVZ・バイトワード比較・BITREV/BYTEREV/FF1 等）と ISA_A のサイズ制限（ALU 系は L のみ）は未実装で、`cf_isa_*` 旗はカバレッジ表にゼロ件で見える。ISA 版とコア版の対応は Freescale 自身が back-annotation により曖昧と訂正しており、cfv2/3/4 の対応は近似。
- **タイミング**：68000 専用のバスサイクル・プリフェッチモデル（`guests/m68k/src/timing.rs`）を持ち、SingleStepTests 68000 の 310,000 件でサイクル数一致を較正済み。

## 対応する OS・ABI と実行環境

- **Linux（`os-linux::m68k`）**：m68k Linux ABI（syscall 表、Line-F 未実装命令補完の受け口、`os-linux::sock`・`os-linux::wait` 正準層を接続済み）。

## 実装の構造と特記事項

2〜22 バイトの可変長命令は `guests/m68k/spec/m68kmin.rs` でオペコード語を定義し、実効アドレス（EA）と拡張語の解析・長さ計算・再符号化は `guests/m68k/src/ea.rs` が担う。68000 の SingleStepTests（`heavy_conformance_sst68000`）は全 317,500 件を実行し、例外・未実装除外対象以外の全件で差分 0 を確認している。

## 既知の簡略化と未対応範囲

- **アドレスエラーの 14 バイト例外フレーム**：例外ベクタ読み出しとフレームプッシュ（`deliver`）はあるが、68000 のアドレスエラー用 14 バイトフレームは未接続。`heavy_conformance_sst68000`（55,606 件）および `heavy_timing_68000` では例外経路を比較対象から除外している。
- **68000 タイミングの対象外**：`DIVU`/`DIVS` の値依存サイクル（`None` 返却）、`TAS`、および例外経路（ベクタフェッチとフレーム書き込み）は `heavy_timing_68000` で除外している。
- **未宣言命令（68000）**：`TAS` は仕様未宣言のためデコード不能（SST の 2,500 件を `unimplemented` 分類）。
- **世代差・拡張の未実装分**：68010 追加命令（`movec`/`moves`/`rtd`/`bkpt`）、BusyBox 非使用の 68020+ 命令（`cas2`/`cmp2`/`chk2`/`trapcc`/`callm`/`rtm`/`pack`/`unpk`）、68040/68060 差分、68881/68882 FPU 算術命令と FPU 例外（現状は `os-linux` が補完する `fmovem`/`fmove` 転送形のみ）、CPU32 は LPSTOP/TBL が、ColdFire は ISA_B/C 追加命令とサイズ制限が未実装（削減群の配線は済）。
- **CLI `cpus`**：`polyisa cpus` の一覧出力には未登録。

## 検証手段

- **OS なし・単体**：`bare_m68kmin`
- **適合テスト・タイミング**：`heavy_conformance_sst68000`、`heavy_timing_68000`
- **ABI・プログラム**：`heavy_abi_m68k`（`syscall.tbl` 直接照合）、`heavy_program_m68k`
