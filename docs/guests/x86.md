# x86

## 概要と対応範囲

16 ビット（8088〜80286）、32 ビット（80386〜Pentium III・generic32）、64 ビット（x86-64 v1〜v4）を単一クレート `guests/x86` で扱う。ユーザーモード命令として整数・x87・MMX・3DNow!・SSE〜SSE4.2・AVX/AVX2・AVX-512・AVX10・AMX・APX（REX2/EGPR）・CET・PKU・WAITPKG・FSGSBASE・TSX 等を対象とする。

- **CPU モデル**：`i8088`、`i186`、`i286`、`i386`、`i486`、`pentium`、`pentium_pro`、`pentium_iii`、`generic32`、`x86_64`、`x86_64_v2`、`x86_64_v3`、`x86_64_v4`（計 13 モデル）。
- **実行モード**：`x86map.rs` で `m64`/`o16`/`o32`/`a16`/`a32`/`a64` を宣言している。実モード実行（`run_m16`）は map 経路でセグメント基底（`selector << 4`）・16 ビット SP・`CS:IP` フェッチを処理する。
- **識別情報**：機能集合から `IDENT_BITS` 経由で CPUID リーフを導出する（`cpuid::derive`）。
- **挙動パラメータ**：`bsf_zero_input`（BSF/BSR の入力 0 時の宛先動作）などを `Model::param` で定義している。

## 対応する OS・ABI と実行環境

- **Linux（`os-linux::x86`）**：`x86_64`、`i386`（x86-32）、`x32`（ILP32）の 3 ABI。マルチプロセス・マルチスレッド（`clone`/`fork`/`execve`/`wait4`/`futex`）、`os-linux::sock`・`os-linux::wait`、`kernel::HostIo` 非同期待ち、x86-64 vsyscall ページ、x86-64 の自分宛てシグナル配送（FXSAVE 配置の rt フレーム）、AMX 利用許可（`arch_prctl`）を実装している。
- **JIT**：`crates/cli/src/run_x86.rs` が `POLYISA_JIT` で x86-64 ホスト JIT に対応している。
- **タイミング**：8088 専用モデル（`timing::I8088`：4 バイトプリフェッチキュー＋BIU バス占有の T-state モデル）、80486・Pentium の `exact` 表を持つ。

## 実装の構造と特記事項

仕様記述は `guests/x86/spec/x86min.rs`（初期の変形列挙経路）、`x86map.rs`（オペコード表 `map`・`0F`/`0F 38`/`0F 3A`・VEX/EVEX/REX2・APX 経路）、`x86cpu.rs`（機能・モデル・識別情報）の 3 ファイルに分かれている。`x86min` 側の命令長判定（`fetch_len`）とオペランド展開（`dispatch`）は `crates/cli/src/run_x86.rs` に残っている。条件フラグは遅延評価で管理し、TSX のトランザクション開始は仕様の許容範囲として常に失敗を返す。

## 既知の簡略化と未対応範囲

- **CPU モデルの世代継承の誤り**：`pentium` が `mmx` を持ち、`pentium_pro` がそれを継承するため、MMX を実装しない Pentium Pro でも MMX 命令が実行できる。現行 `pentium` の CPUID 署名（family 5・model 4）は P55C（Pentium MMX）のものであり、MMX なしの Pentium（P54C）は表現できない。`pentium_ii` 以降の世代モデル追加に合わせて継承関係を分ける。
- **旧列挙経路と PC 幅**：旧 `x86min` 経路は `is64` 真偽値でモードを持ち、`CpuState.eip` が `u32` のため x86-64 の上位 32 ビット PC を保持しない箇所が残る。
- **`statfs` 系 syscall**：`x86_64`（137/138）と `i386`（99/100/268/269）は番号表のみで分岐を持たず `ENOSYS` を返す（BusyBox の `df` は失敗扱い）。
- **x87 の機能ゲートと近似**：
  - ESC（`D8`–`DF`）は 8088 の無視動作を壊さないため `fpu` 機能でゲートしていない。世代ごとの ESC 扱い（8088 無視、486SX INT 7 等）の意味論分岐は未実装。
  - 超越関数（`FSIN`/`FCOS`/`FSINCOS`/`FPTAN`/`FPATAN`/`FYL2X`/`FYL2XP1`/`F2XM1`）は `softfloat` に未実装。`FPREM`/`FPREM1` は倍精度経由の 1 回減算近似（`C2=0` 固定）、`FSCALE` は指数加算の飽和近似、`FXAM` はタグ未モデルのため `0.0` と空スロットを区別しない。`FLDENV`/`FNSTENV` の FIP/FCS/FOP/FDP/FDS は 0 固定。
- **SSE4.2 / ROUND の近似**：`PCMPxSTRx` は `imm[1:0]` を無視して符号なしバイト要素固定で処理する。`ROUNDPS/PD/SS/SD` は丸め指定ビットを受理するが MXCSR の例外マスク・フラグ更新は行わない。
- **デコード差分と接頭辞受理**：
  - `heavy_oracle_llvm` 既知差分（`KNOWN`）：メモリ専用命令（`movbe` 等）の `mod=11` 受理、x87 `mod=11` 未定義スロット受理、SSE1/2 の一部未宣言（`cvtpi2ps`/`movntps`/`cvttps2pi`/`cvtps2pi`/`rsqrtps`/`rcpps`/`cvt*2dq`/`movnti`）、旧列挙経路での必須接頭辞なし形受理。
  - `RDPKRU`/`WRPKRU`・`XGETBV`/`XSETBV`・`CLDEMOTE`・`FXSAVE`/`XSAVE`・`CLFLUSH` の接頭辞受理条件は Intel SDM の例外表との照合が残る。
- **8088 タイミングの対象範囲**：`heavy_timing_8088` の SST CYCL 一致対象は「バスアクセスなし・キューフラッシュなし」の形に限る。スタック・メモリアクセスを伴う形、分岐成立によるキューフラッシュ、`modrm + imm` 形、`cwd`/`aaa` 等の ±1 揺れ、`REP`・文字列命令は対象外。
- **i386 BusyBox**：`heavy_program_i386_applet_probe` で整数命令の欠落は解消済み。未到達アプレットは x87 FPU と実行時間制限のみ。

## 検証手段

- **OS なし・単体**：`bare_x86min`、`bare_x86run`、`bare_x86hello`、`bare_x86file`、`bare_x86ext`
- **適合テスト**：`heavy_conformance_sst8088`、`heavy_conformance_sst80286`、`heavy_conformance_sst80386`
- **デコーダオラクル**：`heavy_oracle_llvm`、`heavy_oracle_xed`
- **実行差分**：`heavy_diff_host`（ホスト x86-64 CPU）、`heavy_diff_sde`（Intel SDE）
- **ABI・プログラム・JIT**：`heavy_abi_uapi`、`heavy_program_busybox`、`heavy_program_busybox_i386`、`heavy_program_i386_applet_probe`、`heavy_program_x32`、`heavy_program_x86ext`、`heavy_program_net`、`heavy_jit_diff`
- **タイミング**：`heavy_timing_8088`、`heavy_timing_i486`、`heavy_timing_pentium`
