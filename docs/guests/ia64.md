# IA-64

## 概要と対応範囲

Itanium〜Itanium 9700 系のユーザーモード命令群（128 ビットバンドル、整数・比較・述語生成、ロード／ストア・ALAT・`chk`・セマフォ、分岐・ループ・回転分岐、レジスタスタックエンジン RSE、82 ビット浮動小数点）を `guests/ia64` で実装している。IA-32 互換実行層は対象外である。

- **CPU モデル**：`generic`、`itanium2`（計 2 モデル）。

## 対応する OS・ABI と実行環境

- **Linux（`os-linux::ia64`）**：ia64 ABI（Linux 6.7 で削除される前のカーネル UAPI。表番号 0–452 に `NR_BASE = 1024` を加算する 355 エントリ）。`break 0x100000` およびゲートページ（`via_break`・`via_epc` 両入口を break 経路へ集約、`AT_SYSINFO`/`AT_SYSINFO_EHDR` 設定）を処理し、`os-linux::sock`・`os-linux::wait` 正準層を接続済み。

## 実装の構造と特記事項

128 ビットバンドルのテンプレート（`bits[4:0]`）から 3 スロットのユニット種別と stop ビットを解決し、41 ビットスロット語（MLX の X スロットは 82 ビット）を `isagen` 生成デコーダで解読する。`Insn` から実行ユニットへの対応表（`insn_unit`）は `guests/ia64/src/bundle.rs` に手書き表として持つ。RSE は 96 エントリのリング駐在域・バッキングストア退避／復元・NaT 集積穴を実装し、82 ビット FP（`{sign, exp17, sig64}`）は `softfloat::ia64ext` を使う。

## 既知の簡略化と未対応範囲

- **CPU モデルの世代混在**：`itanium2` モデルは Itanium 9500 系（Poulson）で追加された命令（`clz`・`mpy4`・`mpyshl4`）まで含むため、Poulson 以前の Itanium 2（McKinley〜Tukwila 系）の命令集合を単独では選べない。`poulson` 旗は独立しているため、モデルの分割で対応する。
- **メモリ・ALAT・順序付けの簡略化**：単一スレッド・コヒーレント模型。ALAT は 16 エントリ FIFO（`chk.a` はレジスタタグ照合、`.c` ロードは常にメモリ再読出し、FP アドバンスドロード未実装のため `chk.a.f` は常に回復分岐）。メモリバリア・順序ヒント（`mf`/`srlz.*`/`sync.i`/`fc`/`fwb`・`.acq`/`.rel`・`ldhint`/`sthint`）は no-op。NaTPage 属性や特権・TLB フォールトは未モデル。`ld16`/`st16`/`cmp8xchg16` は Poulson CPUID 検査を省略。
- **分岐・FP・RSE の簡略化**：分岐予測ヒントは無視。FP 例外配送や特権・IA-32 系命令はユーザーモード範囲外。RSE のバッキングストア書き出し粒度は簡略化しており、浮動小数点テーブル系の一部近似は `crates/softfloat/src/ia64ext.rs` に記載している。
- **Linux ABI**：静的リンク ELF64 を対象とする単一プロセス模型。

## 検証手段

- **OS なし・単体**：`bare_ia64`
- **ABI・プログラム**：`heavy_abi_ia64`（`syscall.tbl` 照合）、`heavy_program_ia64`（busybox-static 1.35.0）
